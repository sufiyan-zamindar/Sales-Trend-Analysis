# 📊 Sales Analysis Dashboard - Task 8

This project is part of a data visualization exercise where we create a **Simple Sales Dashboard** using **Power BI**. The goal is to analyze sales performance based on region, category, month, and product sub-category using interactive visuals.

---

## 🎯 Objective

Create a basic interactive dashboard that shows **Sales performance by product, region, month etc**.

---

## 🛠️ Tools Used

- **Power BI** (for dashboard creation)
- **Python + Pandas** (for data cleaning and preprocessing)

---

## 📁 Dataset

**File:** `T8_Sales_Data.csv`  
**Columns:**
- Order Date
- Region
- Category
- Sub-Category
- Sales
- Quantity
- City
- State
- Ship Mode
- Segment

---

## 🔍 Key Insights

- *Total Sales:* \$345.57K  
- *Total Quantity Sold:* 772 units  
- *Top Region:* West  
- *Top Category:* Technology  
- *Peak Sales Month:* December  
- *Top Performing City:* New York  
- *Top Segment:* Consumer  

---

## 📌 How to Use

1. Clone the repository
2. Open the `.pbix` file using Power BI Desktop
3. Explore the interactive filters and visuals
4. Use slicers to analyze performance based on different dimensions
